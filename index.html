1日目9月12日（土）
CHATAN NIGHT

異国情緒とネオンの街へ

幕張ベイタウンから成田T3へ。着いたらホテルは後回しにして、歩いて楽しい北谷・美浜で夜ごはん。観覧車は2022年になくなっています。

レンタカーはアネックス店 オリックス SAクラス（コンパクト）・ナビ／ETC／幼児用チャイルドシート。貸出 9/12 19:30、返却 9/15 12:00。那覇市安次嶺14-5。免許は従来カード。ホテルの空港シャトルは使わない。
12:20 / 12:39発

京成バス 幕張ベイタウン → 成田T3

本線はベイタウン12:39発 → T3 13:32着。大人1,200円・小児600円。予約不可。行きは車内でIC／現金。1本逃すと13:59発（T3 14:52）で、預け荷物がある日は賭けない。

公式時刻表は京成バス 稲毛海岸・海浜幕張〜成田空港。東関東道の土曜昼は遅れやすい。
15:50 → 19:00

Jetstar GK 成田T3 → 那覇

PNR XLKDQV。国内線は預け・チェックインが出発30分前、ゲート15分前。家族＋荷物なら90〜120分前にターミナルへ。預けは15:20、ゲート15:35が目安。

Jetstar 空港手続き。電車で成田空港駅に着く必要はない。バスはT3直結。
19:30 貸出

那覇空港 → 送迎 約5分

国内線1F外 ⑪-B → アネックス店

横断歩道の先の⑪-Bで「アネックス」と声かけ。送迎約5分。那覇市安次嶺14-5。19:00着便なので預けが出たらすぐ⑪-Bへ。遅れたら店へ電話。

TEL 098-859-3900（8:00–20:00）。那覇空港アネックス店
20:30–22:30 北谷

オリックス発 → 車 約35–45分　／　北谷→ホテル 車 約20分

美浜アメリカンビレッジ

ホテルのドレスダイナー最終入店21:00は使わない。ホテル着は22:30–23:00想定。

2日目9月13日（日）
SEA WALK & WHALE SHARK

海の中へ、それから大水槽へ

午前はかりゆしビーチのシーウォーク。昼は許田、午後はパラセーリングとラテを挟んで、美ら海は16時入り。

ホテル 8:00発が本線 ドレスダイナー朝食は7:00開始。与儀から喜瀬は日曜朝で約45–55分。8:55着・更衣・受付 → 9:15集合。ビーチで長く遊ばない。
09:15集合 / 09:30

ホテル 8:00発 → 車 約45–55分

エムズオーシャン シーウォーク

かりゆしビーチ（名護市喜瀬1996）。ヘルメット型で顔が濡れず、泳げなくてもOK。所要60–90分、水中は約15分。11:00前後終了。5歳は店側が予約OK済み。

公式 mzocean-okinawa.com ／ TEL 080-6489-5607。雨より波・風で欠航。前日夜に海況確認。当日飛行機に乗る人は参加不可（火曜の帰り便には当たらない）。
11:20–12:20

かりゆし 11:10発 → 車 約8–12分

道の駅許田フードコート

ランチ確定。名護市許田1672。開店10:30、L.O. 18:00。そば・ステーキ・タコス・天ぷら。かりゆしから南へ約8–12分。ビーチ目の前に町食堂はないので、ここが手軽さの本線。

日曜は混む。食べ終わらなくても12:20発。ベリー12:45に戻る。TEL 0980-54-0880 ／ yanbaru-b.co.jp
12:45集合 / 13:00

許田 12:20発 → 車 約10–15分

マリンクラブベリー パラセーリング

喜瀬115-2・コートヤード1F。所要約90分、飛行約10分、高度40–50m。基本2人乗り。満5歳・身長120cm以上・体重20–120kg。

公式 berry7.com/kise/parasailing ／ TEL 050-1808-4563。身長が足りなければ大人だけ飛び、子は船上待機（当日空き・3,000円・満3歳から）かビーチ待ち。風で欠航しやすいので前日に確認。
15:05–15:40

喜瀬 14:30発 → 車 約30–40分

The Sinmay（今帰仁・玉城）

喜瀬から約30–40分。目の前で黒糖を削る生黒糖ラテが看板。テイクアウト中心。公式：thesinmay.com

10:00–16:30（L.O. 16:20）。閉店に間に合わせるため、美ら海の前に寄る。混むと10–20分待ち。
16:00–18:00

Sinmay 15:40発 → 車 約15–20分　／　美ら海 18:00発 → ホテル 車 約90–120分

沖縄美ら海水族館

世界最大級の水槽「黒潮の海」。16時入りなので、先に黒潮の海を見る。9月は8:30–18:30、入館締切17:30。

海洋博公園 営業案内。18:00前後に出てホテル直帰。備瀬・万座毛・今帰仁城跡はこの時計では入れない。ホテル着 19:30–20:00。夜食が要るならライカム周辺（ホテルから約5分）。
3日目9月14日（月）
GYOKUSENDO & WHITE TERRACE

太古の地下と、白い街

開園と同時に玉泉洞へ。12:30のエイサーを見てから国際通りでお土産と市場、そのあと瀬長島で夕景。

ホテル 8:00発が本線 朝食は7:00開始。与儀から玉泉洞は車 約50–65分で9:00着（開園と同時）。本線は12:30のエイサーを見て13:15発。ウミカジは15:40着でよい。渋滞で10–20分延びる前提。
09:00–13:15

ホテル 8:00発 → 車 約50–65分

おきなわワールド（玉泉洞）

日本有数の鍾乳洞を歩いて探検。洞内は一年中ひんやり。開園9:00、17:30閉園。先に玉泉洞、王国村を回して12:15にエイサー広場。公式のスーパーエイサーは10:30／12:30／14:30、各約30分。本線は12:30回。

歩きやすい靴。洞内は滑りやすい。ハブパークは苦手ならスキップ。昼食は12:00前に済ませる。ショー時間。終了後すぐ駐車場へ（13:15発）。
13:55–15:10

玉泉洞 13:15発 → 車 約30–40分

国際通り ＆ 牧志公設市場

お土産と市場の匂いをここで取る。滞在は約1時間。紅いもタルト、ちんすこう、シーサー小物は十分揃う。ウミカジは多少遅れてもよいので、15:10には車へ。

駐車はてんぶす那覇／牧志周辺。並んだら路肩にこだわらない。牧志は通りから一本入る。荷物は最小限で。
15:40–17:40

国際通り 15:10発 → 車 約20–30分　／　瀬長島 17:40発 → ホテル 車 約40–50分

瀬長島ウミカジテラス

白い段々の街並みが「日本のアマルフィ」と呼ばれるフォトスポット。夕陽と飛行機雲を見ながら、ソフトや買い物で余韻を。

到着が15:40前後でも夕景は間に合う。お土産の本線は直前の国際通り。ここでは食べ歩きと夕景。日没前は駐車場が混む。空いた列に入れて歩いた方が早いことも。
4日目9月15日（火）
AIRPORT HOMEBOUND

朝食を食べて、南へ

返却はアネックス12:00。朝の空きは琉球ガラス村が候補。決めたら13:15便と17:25のバスを守る。

返却はアネックス 12:00予約 本線は11:45店着（送迎約5分）。朝の空きの候補が琉球ガラス村（9:30着・10:00体験・11:10発）。行くなら給油は小禄で先に。行かないなら8:30発でも余裕がある。
07:00–08:15

ホテル朝食 → 8:30チェックアウト

ドレスダイナー 7:00–10:30。8:30チェックアウト。ガラス村に行くなら小禄で先に給油。国際通りは3日目に済んでいる。

候補 09:30–11:10

ホテル 8:30発 → 車 約50–65分（小禄で給油）　／　ガラス村 11:10発 → 車 約20–30分

候補：琉球ガラス村（糸満市福地）

未確定。行くなら開園9:30、吹きガラスは10:00開始なら9:30着。体験そのものは約10分。5歳は火を使うため公式は小学生以上。子は絵付けなど当日持ち帰れるメニュー（約40分）。完成したグラスは一晩冷却するため当日は持ち帰れず、7日後以降に郵送（県外1,500円）。行かないときの空きは中城城跡や浦添大公園（遊具）でも切れる。

糸満市字福地169。ナビは電話 098-997-4784 かマップコード 232 336 227（西崎営業所を選ばない）。吹きは予約制・当日朝9時まで。体験予約。公式。11:30発だと店着が12:00ぎりぎり。
11:45返却 → 13:15

ガラス村に行くなら 11:10発 → 車 約20–30分　／　行かないならホテル 8:30発でも11:45前着

アネックス返却 → Jetstar GK 那覇 → 成田T3

PNR CR8DPA。那覇 13:15 → 成田T3 15:55。那覇市安次嶺14-5。送迎約5分で国内線へ。ホテルの12:00発シャトルは間に合わない。

17:25発 → 18:35着

京成バス 成田T3 → 幕張ベイタウン

本線は T3 17:25発 → ベイタウン 18:35着。帰りは空港で切符を買ってから並ぶ（車内精算ではない）。のりばは 1F 10番（到着ロビーと同じ階）。

16:25発（ベイタウン 17:35）は定刻かつ手荷物のみのとき。遅れたら 18:15 → 19:11。公式は京成バス。

旅のメモ

  • 往路 PNR XLKDQV（NRT T3 15:50 → OKA 19:00）。復路 PNR CR8DPA（OKA 13:15 → NRT T3 15:55）。
  • 京成バスは予約不可。行きは車内精算、帰りは空港で切符を買って T3 1F 10番。本線は行き12:39／帰り17:25。
  • Jetstar国内線は預け・チェックイン出発30分前、ゲート15分前。家族＋荷物なら90〜120分前。
  • 車はオリックス那覇空港アネックス店（那覇市安次嶺14-5、TEL 098-859-3900）。⑪-Bで「アネックス」。貸出9/12 19:30、返却9/15 12:00（店着11:45目安）。
  • 4日目の朝は琉球ガラス村が候補（未確定）。行くなら9:30着・11:10発。行かないなら8:30発でもアネックス11:45に間に合う。
  • 車の時間は目安。渋滞で10–20分延びる前提。ホテル発は海の日・洞窟の日とも8:00、帰り8:30。
  • シーウォークはエムズオーシャン（かりゆしビーチ）。波・風で欠航。前日に 080-6489-5607。
  • 日曜ランチは道の駅許田。12:20に切ってベリー12:45へ。5歳が飛ぶなら身長120cm以上。
  • 美ら海は16時入り、黒潮の海を先に。そのあとはホテル直帰。夜食はライカム。
  • 観覧車はもう無い。アメリカンビレッジの夜は街並みとサンセットビーチが主役。
